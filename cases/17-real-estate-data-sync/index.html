Use Case 17 · real estate

Автоматизация обновления данных по строящимся объектам недвижимости

Омниканальная система сбора и структурирования данных от застройщиков

Срок
120 рабочих дней
Технология
Python, OpenAI Whisper, Azure Document Intelligence
Метрика
с 2 часов/день до 0
Бизнес-задача
Клиент — консалтинговое агентство по управлению недвижимостью — получал обновления по объектам в хаотичном формате: файлы Excel с планировками, PDF-презентации, голосовые сообщения от менеджеров застройщика в WhatsApp, PowerPoint с рендерами. Актуализация карточек объектов в CRM занимала до 2 часов ежедневно, при этом данные нередко устаревали раньше, чем попадали к менеджерам продаж.
Реализованное решение
Построена система автоматического приёма, распознавания и структурирования обновлений от застройщиков в любом формате с последующей загрузкой актуальных данных в CRM через API.
Ключевые компоненты системы
01
Универсальный приёмник файлов
система принимает обновления из нескольких каналов: email-вложения, Telegram-бот для менеджеров застройщика, shared-папка. Поддерживаемые форматы: PPTX, DOCX, XLSX, PDF, MP3, OGG (голосовые сообщения), MP4.
02
Speech-to-Text модуль
голосовые сообщения от менеджеров автоматически транскрибируются с высокой точностью. Система понимает профессиональную лексику рынка недвижимости, названия жилых комплексов, планировок и корпусов.
03
Мультиформатный парсер документов
для каждого типа файла применяется специализированный pipeline: OCR для PDF и сканов, структурный парсер для Excel-таблиц с ценами, извлечение текстового слоя из PPTX-презентаций.
04
LLM-экстрактор ключевой информации
языковая модель извлекает из документов и транскриптов структурированные данные: статус строительства, сроки сдачи по корпусам, изменения в планировках, актуальные цены и действующие скидки, условия рассрочки и ипотеки.
05
Структурирование в JSON
все извлечённые данные приводятся к единому JSON-формату, совместимому со схемой CRM клиента. Консистентность данных независимо от источника и формата входящего документа.
06
Валидация перед загрузкой
система проверяет корректность данных перед отправкой в CRM: диапазоны цен (защита от опечаток), даты сдачи (не в прошлом), обязательные поля. При обнаружении аномалий — создаётся задача на ручную проверку.
07
Автоматическая отправка в CRM через API
подтверждённые данные поступают в CRM в режиме реального времени. История изменений сохраняется: менеджеры видят, что именно изменилось и когда.
Технические особенности
Система построена на модульной архитектуре: каждый тип файла обрабатывается своим pipeline, что позволяет добавлять новые форматы без переработки основной логики. Speech-to-Text реализован на базе Whisper, обработка документов — через Azure Document Intelligence и python-pptx/openpyxl для нативных форматов. Ключевым вызовом стала вариативность входных данных: каждый застройщик имеет свой шаблон и терминологию. Решением стал few-shot prompting с примерами от каждого застройщика — система «настраивается» на особенности конкретного источника. Время от получения файла до обновления карточки в CRM — менее 3 минут. Ежедневные затраты на актуализацию данных сократились с 2 часов до нуля. ___ Технология: Python, OpenAI Whisper, Azure Document Intelligence, OpenAI API, REST API CRM Время внедрения: 120 рабочих дней
