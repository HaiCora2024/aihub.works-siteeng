Use Case 18 · performance tracking

ИИ-система performance-трекинга сотрудников

Многопараметрический скоринг с персонализированной коммуникацией и action plans

Срок
70 рабочих дней
Технология
Python, OpenAI API, Telegram Bot API
Метрика
78% открывают отчёты в день получения
Бизнес-задача
Клиент — крупная сеть фитнес-клубов — управлял командой из 150+ тренеров и сотрудников сервиса. Существующая система KPI была непрозрачной: сотрудники не понимали, на основе каких данных оцениваются, не получали своевременной обратной связи и не знали, что именно нужно улучшить. HR-команда тратила 2 недели в квартал на ручной сбор и расчёт показателей. Текучесть кадров оставалась высокой.
Реализованное решение
Построена AI-система, которая автоматически собирает данные по 12+ метрикам, рассчитывает многопараметрический скоринг, визуализирует результаты и отправляет каждому сотруднику персонализированный отчёт с конкретными рекомендациями.
Ключевые компоненты системы
01
Многопараметрический скоринг (100-балльная шкала)
система оценивает эффективность каждого сотрудника по 12+ метрикам: клиентские показатели (NPS, продления, отзывы), продажи, посещаемость и пунктуальность, внутренние показатели. Каждая метрика имеет настраиваемый вес в итоговом балле.
02
Автоматизированный сбор данных
система интегрирована с CRM клуба, расписанием, кассовой системой и платформой для отзывов. Данные агрегируются автоматически — без ручного ввода.
03
Система визуализации с цветовой индикацией
итоговый балл определяет «клуб» сотрудника: зелёный (топ-перформеры, 80–100 баллов), жёлтый (средний уровень, 60–79 баллов), красный (зона риска, ниже 60 баллов). Визуализация включает радарную диаграмму по всем метрикам и динамику за период.
04
Персонализированные performance-отчёты
каждый сотрудник автоматически получает индивидуальный отчёт: итоговый балл, позиция в команде (анонимный рейтинг), детализация по каждой метрике, сравнение с предыдущим периодом.
05
Генератор персонализированных action plans
на основе профиля слабых метрик LLM формирует конкретные рекомендации для каждого сотрудника: не общие советы, а специфические действия. Например: «запишитесь на тренинг по продажам» или «обратите внимание на опоздания в среду — у вас 3 случая за месяц».
06
Автоматизированная коммуникация
система управляет всей коммуникацией: напоминания сотрудникам из жёлтой и красной зон, поздравления топ-перформерам, уведомления руководителям о сотрудниках в зоне риска.
07
HR-дашборд
руководство видит сводную картину по всей команде: распределение по клубам, динамику изменений, отделы с наибольшим числом сотрудников в красной зоне.
Технические особенности
Система реализована как набор автоматических процессов с расписанием: еженедельный расчёт оперативных метрик и ежемесячный полный пересчёт скоринга. Интеграции с CRM и расписанием реализованы через REST API. Генерация персонализированных action plans — наиболее технически интересная часть: LLM получает профиль конкретного сотрудника (все метрики, динамика, специализация) и генерирует рекомендации, которые сотрудники воспринимают как написанные лично для них, а не как шаблонный отчёт. Система сократила время HR-команды на составление отчётов с 2 недель до 0. Вовлечённость сотрудников в собственные показатели выросла: 78% сотрудников открывают отчёты в день получения. ___ Технология: Python, OpenAI API, REST API CRM, Google Sheets / PostgreSQL, Telegram Bot API Время внедрения: 70 рабочих дней
