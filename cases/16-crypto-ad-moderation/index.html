Use Case 16 · crypto moderation

AI-модерация рекламы в криптосегменте

Интеллектуальная система проверки рекламных материалов с многоуровневым скорингом

Срок
60 рабочих дней
Технология
Python, OpenAI API, OCR, PostgreSQL
Метрика
нагрузка на команду −80%
Бизнес-задача
Клиент — рекламная платформа, специализирующаяся на крипто- и Web3-сегменте — столкнулась с волной недобросовестных рекламодателей: скам-проектов, манипулятивных обещаний доходности, нелицензированных финансовых продуктов. Ручная модерация командой из 4 человек не справлялась с объёмом: рассмотрение одной заявки занимало 20–40 минут, очередь растягивалась на 3–5 дней. Репутационные риски росли.
Реализованное решение
Разработана AI-система модерации, которая автоматически проверяет рекламные материалы по 22 критериям, классифицирует их по уровню риска и формирует детальный отчёт с обоснованием для каждого решения.
Ключевые компоненты системы
01
Правила модерации по 22 критериям
структурированный свод правил охватывает: гарантии доходности, признаки финансовой пирамиды, нелицензированную деятельность, манипулятивные триггеры, ложные партнёрства с известными брендами, признаки скама и rug pull.
02
OCR-модуль анализа визуальных материалов
извлекает текст с баннеров, изображений и видео-превью. Распознаёт мелкий текст с дисклеймерами и скрытые манипулятивные элементы.
03
Проверка токенов и проектов
автоматически запрашивает данные о рекламируемом токене/проекте на CoinGecko, CoinMarketCap, RugCheck, токен-сканерах. Проверяет контракт, ликвидность, историю транзакций.
04
Репутационный анализ рекламодателя
система собирает отзывы о рекламодателе на тематических форумах, агрегаторах жалоб и в социальных сетях. Проверяет историю предыдущих рекламных кампаний.
05
Скоринговая система
каждый материал получает итоговый балл риска. Классификация: зелёная зона (автоматическое одобрение), жёлтая зона (требует ревью модератора), красная зона (автоматический отказ с формированием причин).
06
Генератор отчётов о нарушениях
для каждого материала формируется детальный отчёт: какие критерии сработали, с каким весом, что именно найдено (цитата из текста или скриншот), ссылки на источники при проверке репутации.
07
Аудит-логи
все решения системы фиксируются с полным набором данных: время проверки, версия правил, промежуточные результаты каждого модуля. Полная прозрачность для внутреннего аудита и при спорах с рекламодателями.
Технические особенности
Система реализована как многоэтапный pipeline: каждый модуль проверки работает параллельно и независимо, результаты агрегируются на финальном этапе скоринга. Это позволяет проверять один материал за 2–4 минуты против 20–40 минут при ручной модерации. LLM используется для семантического анализа текста и классификации нарушений, OCR — для обработки визуальных материалов, внешние API — для on-chain верификации. Важным архитектурным решением стала документируемость каждого вывода AI: система не просто выносит вердикт, но цитирует конкретные фрагменты материала, которые стали основанием — это критично для юридически значимых споров с рекламодателями. Система снизила нагрузку на команду модерации на 80% и сократила время проверки с 3–5 дней до 2–4 часов. ___ Технология: Python, OpenAI API, OCR, CoinGecko API, Web-scraping, PostgreSQL Время внедрения: 60 рабочих дней
