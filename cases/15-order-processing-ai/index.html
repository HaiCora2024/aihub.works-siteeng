Use Case 15 · order processing

AI-система автоматической обработки заказов

Интеллектуальная обработка документов с интеграцией в 1С

Срок
70 рабочих дней
Технология
Python, Azure Document Intelligence, OpenAI API
Метрика
с 3–4 часов до 20 мин/день
Бизнес-задача
Клиенту — оптовой компании — требовалась система автоматической обработки входящих заказов от покупателей. Заказы поступали в разных форматах: сканированные PDF, таблицы Excel, документы Word. Менеджеры вручную перебивали позиции в 1С, тратя 3–4 часа в день, при этом регулярно допуская ошибки в артикулах и количестве. Несовпадение наименований товаров у клиента и в номенклатуре компании приводило к задержкам и конфликтам.
Реализованное решение
Построена AI-система, которая принимает документы любого формата, автоматически извлекает позиции заказа, сопоставляет их с внутренней номенклатурой и формирует готовое коммерческое предложение с последующей передачей данных в 1С.
Ключевые компоненты системы
01
Универсальный приёмник документов
принимает файлы в форматах PDF, XLSX, XLS, DOCX через email, Telegram-бот или веб-форму. Автоматически определяет формат и маршрутизирует на соответствующий парсер.
02
OCR-модуль
распознаёт текст со сканированных и рукописных документов с точностью до 98%. Обрабатывает таблицы, рукописные пометки, печати и штампы.
03
NLP-движок извлечения позиций
с помощью языковой модели извлекает из неструктурированного текста наименование товара, артикул, количество, единицу измерения, цену. Обрабатывает аббревиатуры, опечатки и нестандартные обозначения.
04
Семантический матчинг номенклатуры
сопоставляет извлечённые позиции с внутренним каталогом компании методом семантического поиска (векторные эмбеддинги). Находит соответствия даже при расхождении в названии, бренде или единицах измерения. При низкой уверенности — флагирует позицию для ручной проверки.
05
Генератор коммерческого предложения
автоматически формирует КП в фирменном шаблоне с актуальными ценами, остатками и сроками поставки.
06
Интеграция с 1С
через REST API передаёт подтверждённые позиции заказа напрямую в бухгалтерскую систему, исключая ручной ввод.
07
Контроль качества и логирование
каждая позиция получает скоринговую оценку уверенности. Позиции ниже порога автоматически выделяются для проверки менеджером. Система ведёт полный журнал обработки каждого документа.
Технические особенности
Система построена на связке OCR (Tesseract / Azure Document Intelligence) + LLM для извлечения сущностей + векторная база данных для семантического поиска по номенклатуре. Интеграция с 1С реализована через odata REST API. Критичным оказался дизайн fallback-логики: для позиций, которые система не смогла сопоставить с уверенностью выше порога, автоматически создаётся задача в CRM с контекстом распознавания — менеджер видит, что именно система поняла из документа и почему не уверена в соответствии. Система обрабатывает один документ за 15–40 секунд, что сократило время обработки заказов с 3–4 часов до 20 минут в день на весь поток. ___ Технология: Python, Azure Document Intelligence, OpenAI API, 1С REST API, векторная БД Время внедрения: 70 рабочих дней
